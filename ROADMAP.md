# TalkToBook roadmap

## Now

1. Keep YouTube and local Markdown inputs, cleaning, covers, attribution, and
   dual Markdown/EPUB output.
2. Keep the Kobo desk loop (preview, ingest, copy-only sync) as the operator
   surface.

## Next

1. Add fixtures and regression tests for extraction, attribution, reflow,
   metadata, and failures.
2. Package the public web path so a clean machine can reproduce a book without
   environment archaeology.
3. Cover providers beyond ASCII if Hung drops keys.

## Later

Choose broader public distribution only after tests and recovery are solid.
Bulk ingestion or public hosting must not weaken creator credit, source rights,
or binary-storage rules. Kindle remains a preview frame, not a sync target.
